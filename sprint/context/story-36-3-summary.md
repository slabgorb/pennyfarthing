## Objective

Enrich Bash tool spans with command execution context following the established pattern from Story 36-2 (Read/Edit enrichment). This includes redacting secrets, capturing exit codes, summarizing output, and including execution metadata.

## Implementation Summary

### Changes Made

#### 1. Type Definitions (file-enrichment.ts)
- Added `BashEnrichment` type with fields:
  - `command`: string (redacted secrets)
  - `exitCode`: number | undefined
  - `outputSummary`: string (first 5 + last 5 lines if truncated)
  - `duration`: number (milliseconds)
  - `workingDirectory`: string

#### 2. Core Functions (file-enrichment.ts)
- **`redactSecrets(command: string)`** - Removes sensitive data patterns:
  - Passwords, API keys, tokens
  - AWS credentials, GitHub tokens
  - Long base64 strings
  - Patterns: `key=value`, `key: value`, `--key=value`

- **`createOutputSummary(output: string)`** - Intelligent output truncation:
  - Full output if < 500 characters
  - First 5 + last 5 lines if longer, with [TRUNCATED] indicator
  - Handles empty/whitespace-only output gracefully

- **`extractExitCode(span, context)`** - Exit code extraction:
  - Checks span attributes for tool_output JSON
  - Parses exit code from command execution results
  - Returns undefined if not available

- **`enrichBashSpan(span, correlation)`** - Main enrichment function:
  - Looks up correlation via toolId
  - Retrieves command from messageContext
  - Applies redaction and output summary
  - Marks span as enriched

#### 3. Integration (otlp-receiver.ts)
- Added Bash case in `processLogEvents()` (line ~816)
- Calls `enrichBashSpan()` for Bash tool spans
- Updated `ToolEvent` interface to include BashEnrichment
