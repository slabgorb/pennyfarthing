## Technical Context

### Current Architecture
The compare page uses a React island (QueryBuilder.tsx) with local useState for:
- `oceanFilters` - Per-dimension min/max ranges
- `selectedRoles` - Set of selected role filters
- `selectedThemes` - Set of selected theme filters
- `expression` - Custom OCEAN expression string
- `sortBy` - Current sort option

Character selection for comparison uses `compare-selection.ts` which manages a `SelectionState` with 2-4 character limit.

### Implementation Approach

**1. URL State Encoding (AC1, AC2)**
Create `useUrlState` hook or integrate with QueryBuilder:
```typescript
// Encode state to URL params
const params = new URLSearchParams();
if (expression) params.set('q', expression);
if (sortBy !== 'name') params.set('sort', sortBy);
selectedRoles.forEach(r => params.append('role', r));
selectedThemes.forEach(t => params.append('theme', t));
// OCEAN filters: o=3-5, c=4, etc.
Object.entries(oceanFilters).forEach(([dim, range]) => {
  if (range) params.set(dim.toLowerCase(), `${range.min}-${range.max}`);
});
// Selected characters for comparison
selectedIds.forEach(id => params.append('char', id));
```

**2. URL Reading on Load (AC2)**
In useEffect on mount, read URLSearchParams and initialize state:
```typescript
useEffect(() => {
  const params = new URLSearchParams(window.location.search);
  // Parse and set initial state from URL
}, []);
```

**3. Browser History (AC4)**
Use `history.replaceState()` for filter changes (no new history entry).
Listen to `popstate` event for back/forward navigation.

**4. Share Button (AC3)**
Add button that copies current URL to clipboard:
```typescript
const handleShare = async () => {
  await navigator.clipboard.writeText(window.location.href);
  // Show toast/feedback
};
```
