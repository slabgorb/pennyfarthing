## Problem Description

User reports that after selecting a font in the settings panel, the change doesn't take effect. The font setting isn't working.

**Likely causes to investigate:**
1. Settings saved but not applied to xterm.js terminal instance
2. CSS variables not being updated when settings change
3. Font value not read on startup/reload
4. IPC communication not propagating font changes to renderer
