### What Was Built

A new `agent-context.ts` module that tracks which Pennyfarthing agent (SM, TEA, Dev, Reviewer) is active during Claude Code sessions. This enables per-agent cost tracking and performance comparison.

**Key Functions:**
- `setAgentContext(agent?)` - Set current agent from env var or explicit value
- `getAgentContext()` - Get active agent
- `getTokenStatsByAgent()` - Return per-agent token breakdown
- `aggregateTokensForAgent()` - Track tokens by active agent

**Integration Points:**
- `span-hierarchy.ts` tags all AgentSpans with `pennyfarthing.agent` attribute
- `otlp-receiver.ts` accumulates tokens by agent via `aggregateTokensForAgent()`
