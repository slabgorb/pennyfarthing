## Story Description
Guided mode for /theme-maker command:
1. Ask for theme universe description
2. For each of 10 agents, suggest 3-4 fitting characters
3. User picks one (or "Other" for custom)
4. AI fills in style/trait/quote for selected characters
5. Preview complete theme and confirm
