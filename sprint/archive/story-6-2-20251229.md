## Description
User provides a universe/concept, AI generates all 10 agent personas.

Flow:
1. Ask: "Describe your theme universe" (text input)
2. AI generates all 10 agents with appropriate characters
3. Show preview of generated theme
4. Ask: Confirm, regenerate, or edit?
5. Write complete theme file
