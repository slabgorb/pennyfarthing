## Description
Create QueryBuilder.tsx React component for /compare page.
- OCEAN dimension filters (sliders or dropdowns, 1-5)
- Expression input field for advanced queries
- Role filter: checkboxes for 10 roles
- Theme filter: multi-select with search
- Sort options: by OCEAN dimension, alphabetically
- Submit triggers results display

## Acceptance Criteria
- [ ] React island hydrates on /compare page
- [ ] All filter types functional
- [ ] Expression input accepts OCEAN syntax
- [ ] Filters combine with AND logic
- [ ] Results update on filter change

### Data Available
- `themes.json` generated at build time with all 64 themes

- Roles: sm, tea, dev, reviewer, architect, pm, tech-writer, ux-designer, devops, orchestrator

### Pattern to Follow
```tsx

```

### OCEAN Expression Syntax (from story 13-8)
- `O>=4` - Openness >= 4
- `C=3` - Conscientiousness = 3
- `E<=2 AND A>=4` - Combined filters
