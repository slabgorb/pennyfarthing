## Description

The context meter currently checks the most recent Claude transcript in the project directory, which may be the wrong session (e.g., a terminal session instead of Cyclist's PTY session).

Need to track Cyclist's Claude session ID and use it for:
- Context usage checking (check correct transcript)
- Agent state lookups (which agent is active in THIS session)
- Story context (which story THIS session is working on)

## Implementation Plan

1. ClaudeService already captures session_id from init messages
2. Pass session ID to getContextUsage() and check-context.sh
3. Add --session flag to check-context.sh to target specific transcript
4. Use session ID for agent state lookups

## Files to Modify

- packages/cyclist/src/main.ts (pass session to context polling)
- packages/cyclist/src/api/context.ts (accept session param)
- scripts/check-context.sh (add --session flag)

## Acceptance Criteria

- [ ] ClaudeService session ID passed to context polling
- [ ] check-context.sh accepts --session <id> flag
- [ ] Context checks target Cyclist's session transcript only
- [ ] Agent state lookups use session-specific files
- [ ] Multiple Cyclist instances don't interfere with each other
