## Technical Context

### Existing Patterns to Reuse

**Fuzzy Search (ThemeBrowser.js:157-169):**
```javascript
export function filterThemesBySearch(themes, query) {
  if (!query?.trim()) return themes;
  const terms = query.toLowerCase().split(/\s+/);
  return themes.filter(theme => {
    const searchable = `${theme.name} ${theme.description || ''}`.toLowerCase();
    return terms.every(term => searchable.includes(term));
  });
}
```

**Favorites Storage:** `settings.pennyfarthing.favorites` (string array of theme IDs)

**Theme Metadata Loading:** IPC via `window.electronAPI.settings.getThemeMetadata()`

**Keyboard Shortcut Pattern:** Menu item in main.ts with `accelerator: 'CmdOrCtrl+K'`
