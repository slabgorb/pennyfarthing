## Story Context

Extend benchmarking to compare personas along categorical dimensions beyond just theme names. This enables analysis like "comedic personas outperform serious ones on creative tasks" or "historical personas do better at research than action-oriented ones."

## Acceptance Criteria

- [x] Theme files include dimension tags (tone, era, genre, energy)
- [x] At least 10 anchor themes tagged with all dimensions
- [x] Job-fair aggregator groups results by dimension
- [x] Differential report shows performance by dimension value
- [x] Statistical significance noted for dimension comparisons
- [x] API endpoint for dimension-filtered queries

## Implementation Summary

### 1. Dimension Schema (theme YAML)
```yaml
dimensions:
  tone: comedic | serious | satirical | dramatic
  era: historical | contemporary | futuristic | timeless
  genre: action | drama | sci-fi | fantasy | literary | comedy
  energy: high-energy | measured | contemplative
```

### 3. New Types (job-fair-aggregator.ts)
- `DimensionName` - 'tone' | 'era' | 'genre' | 'energy'
- `DimensionValues` - Valid enum values per dimension
- `ThemeDimensions` - Dimensions block shape
- `DimensionValueStats` - Stats for one dimension value
- `DimensionComparison` - Pairwise comparison with significance
- `DimensionStats` - Full aggregation result

### 4. New Functions (job-fair-aggregator.ts)
- `aggregateByDimension(dimension, resultsDir, themesDir)` - Groups by dimension
- `getDimensionValues(dimension, themesDir)` - Lists values with counts
- `generateDifferentialReport(dimension, resultsDir, themesDir)` - Markdown report
- `calculateSignificance()` - Cohen's d effect size calculation

### 5. API Endpoints (packages/cyclist/src/api/benchmark.ts)
- `GET /api/benchmark/dimensions` - List all dimensions with values
- `GET /api/benchmark/dimensions/:dimension` - Stats for dimension
- `GET /api/benchmark/dimensions/:dimension/report` - Markdown report
- `GET /api/benchmark/aggregate` - Overall aggregation (from 7-4)
