### Agent Detection Strategy

**IMPORTANT:** Multiple Claude sessions may run against the same codebase.

1. If `CYCLIST_SESSION_ID` is set:
   - Read `.session/agents/{SESSION_ID}` for THIS session's agent
   - Watch only that specific file for changes

2. If `CYCLIST_SESSION_ID` is NOT set (fallback):
   - Find most recently modified file in `.session/agents/`
   - Watch entire directory for changes
