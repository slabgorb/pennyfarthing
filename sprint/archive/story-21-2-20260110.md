## Story Overview

Create a `/prime` command that quickly loads essential project context at agent activation. Hook into `agent-session.sh` to auto-invoke on agent start, reducing cold-start overhead.

## Acceptance Criteria

- [x] AC1: /prime command loads essential context files
- [x] AC2: Context loaded in priority order (CLAUDE.md first)
- [x] AC3: agent-session.sh calls /prime on start

3. **Active session** - If work in progress

### File 3: .claude/scripts/prime.sh

Implementation script:

```bash
#!/usr/bin/env bash
# prime.sh - Load essential project context

set -euo pipefail

# Find project root
source "$(dirname "$0")/utils/find-root.sh"

QUIET=false
MINIMAL=false
FULL=false

# Parse args
while [[ $# -gt 0 ]]; do
    case $1 in
        --quiet) QUIET=true; shift ;;
        --minimal) MINIMAL=true; shift ;;
        --full) FULL=true; shift ;;
        *) shift ;;
    esac
done

# 1. CLAUDE.md files (always)
if [[ -f "$PROJECT_ROOT/CLAUDE.md" ]]; then
    cat "$PROJECT_ROOT/CLAUDE.md"
fi
if [[ -f "$HOME/.claude/CLAUDE.md" ]]; then
    cat "$HOME/.claude/CLAUDE.md"
fi

[[ "$MINIMAL" == "true" ]] && exit 0

# 2. Sprint summary (extract key info only)
if [[ -f "$PROJECT_ROOT/sprint/current-sprint.yaml" ]]; then
    echo "---"
    echo "# Sprint Context"
    yq '.sprint | "Sprint " + (.number | tostring) + ": " + .goal' "$PROJECT_ROOT/sprint/current-sprint.yaml"
    yq '.summary | "Progress: " + (.completed_points | tostring) + "/" + (.total_points | tostring) + " points"' "$PROJECT_ROOT/sprint/current-sprint.yaml"
fi

# 3. Active session (if exists)
SESSION_FILE=$(find "$PROJECT_ROOT/.session" -name "*-session.md" -type f 2>/dev/null | head -1)
if [[ -n "$SESSION_FILE" ]]; then
    echo "---"
    echo "# Active Session"
    head -50 "$SESSION_FILE"
fi

# 4. Domain docs (--full only)
if [[ "$FULL" == "true" ]]; then
    for doc in "$PROJECT_ROOT/.claude/project"/CLAUDE-*.md; do
        [[ -f "$doc" ]] && cat "$doc"
    done
fi
```
