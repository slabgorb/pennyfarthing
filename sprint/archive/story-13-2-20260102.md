## Description

## Technical Approach

### Components to Create

1. **Base.astro Layout** (`src/layouts/Base.astro`)
   - HTML5 document structure
   - SEO meta tags (title, description, og:tags)
   - Slot for page content
   - Import global.css for Tailwind

2. **Header Component** (`src/components/Header.astro`)
   - Logo/site title
   - Desktop navigation links
   - Mobile hamburger menu trigger

3. **Navigation Component** (`src/components/Nav.astro` or integrated)
   - Links: Themes, Compare, Benchmarks, Favorites
   - Active state styling
   - Responsive behavior

4. **MobileMenu Component** (`src/components/MobileMenu.tsx`)
   - React island for interactivity
   - Hamburger toggle
   - Slide-out or dropdown menu
   - `client:load` directive

5. **Footer Component** (`src/components/Footer.astro`)
   - Project links (GitHub, docs)
   - Copyright/attribution
