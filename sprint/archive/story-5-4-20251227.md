## Description

CLI command to display full details of a theme.

Usage:
```bash
pennyfarthing theme show
pennyfarthing theme show star-trek
```

Output format:
```
Theme: star-trek
Description: Star Trek TOS inspired personas

Agents:
  sm:
    character: Captain Kirk
    style: Bold leader who makes decisive calls
    quote: "Risk is our business..."
  tea:
    character: Spock
    style: Logical, precise, analytical
    quote: "Fascinating..."
  ...
```
