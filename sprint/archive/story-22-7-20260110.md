**Problem:** Token counts (OTLP telemetry) showed cumulative session totals, while context meter (check-context.sh) showed current context window. These are fundamentally different metrics but weren't distinguished in UI.

**Solution:** Display both with clear labels:
- "Session: ↓X ↑Y" - Cumulative session totals from OTLP
- "Context: Xk" - Current context window tokens from transcript (ground truth)
- Context meter (%) - Visual percentage from transcript
