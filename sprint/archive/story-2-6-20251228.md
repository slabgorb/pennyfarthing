## Description

Add sidecar template files to pennyfarthing-dist/templates/ so the CLI installs lean starter content instead of empty files.

Previously `pennyfarthing init` created empty sidecars with just headers. Now installs templates with:
- Standard 3-file structure (patterns.md, gotchas.md, decisions.md)
- Section headers and placeholder prompts
- Example format for each entry type
