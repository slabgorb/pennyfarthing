**Implementation Summary:**
1. `detect_drift()` function (~55 lines):
   - Scans `git log --merges` for past 7 days
   - Uses `extract_story_id()` to parse branch names
   - Uses `get_story_field()` to check YAML status
   - Queries Jira via `jira issue view` for issue status
   - Returns drifted stories in `story_id:yaml_status:jira_status` format
   - Detects drift if YAML or Jira is not "Done"

2. `reconcile_drift()` function (~40 lines):
   - Calls `update_story_status()` to mark YAML done
   - Calls `jira issue move` to transition Jira to Done
   - Logs both YAML and Jira reconciliation to `.session/reconciliation.log`

3. Step 2.5 in workflow-status-check.md:
   - Sources sprint-common.sh and calls detect_drift
   - Reports drifted stories with YAML and Jira status
   - Offers y/n auto-reconcile option for both systems
