# Story 3-2: Add automatic warning at 70% threshold

## Story Overview
- **Epic:** 3 - Context Management & Circuit Breaker
- **Points:** 3
- **Priority:** P1
- **Repos:** pennyfarthing

## Technical Approach

Use Claude Code's `PreToolUse` hook to check context and inject warnings.

### Implementation Plan

1. **Create `context-warning.sh` hook**
   - Location: `pennyfarthing-dist/scripts/hooks/context-warning.sh`
   - Calls `check-context.sh` to get current percentage
   - At 70%+: outputs warning message
   - At 85%+: outputs critical warning (prep for 3-3)
   - Returns quickly if under threshold (no delay)

2. **Add hook to settings template**
   - File: `pennyfarthing-dist/templates/settings.local.json.template`
   - Add PreToolUse matcher for all tools (or high-token ones)
   - Consider: run on every tool vs. every Nth tool

3. **Warning message format**
   - Include current percentage
   - Suggest: "Consider wrapping up current task"
   - Suggest: "Handoff to next agent recommended"
   - Keep concise (don't waste tokens on the warning itself)

### Key Files
- `scripts/hooks/context-warning.sh` - new hook
- `scripts/check-context.sh` - existing, provides percentage
- `.claude/settings.local.json` - hook registration
- `pennyfarthing-dist/templates/settings.local.json.template` - template for new installs

## Acceptance Criteria

- [ ] Warning includes actionable suggestions
