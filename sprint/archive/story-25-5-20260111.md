## What This Story Accomplishes

Currently, Cyclist uses regex heuristics to detect questions, choices, and handoffs from Claude's output. This works ~80% of the time but will never be perfect because natural language is ambiguous.

Story 25-5 adds **structured markers** - hidden HTML comments that Pennyfarthing agents emit to signal their intent explicitly. Cyclist can detect these with 100% accuracy while keeping them invisible to users.

## Current State

**Cyclist (quick-actions.js:493-522):**
- `processMessageForQuickActions()` checks handoffs → lists → questions
- Detection uses regex patterns against last paragraph
- No marker detection exists yet

**Pennyfarthing Agents:**
- SM presents story choices to user (no markers)
- TEA/Dev/Reviewer output assessment templates (no markers)
- Handoffs use natural language ("invoke /reviewer to continue")

## Technical Approach

**Marker Format:**
```html
<!-- CYCLIST:QUESTION:yesno -->
<!-- CYCLIST:CHOICES:1,2,3 -->
<!-- CYCLIST:HANDOFF:/reviewer -->
```

**Implementation:**

1. **Cyclist Side (quick-actions.js):**
   - Add `detectStructuredMarker()` function
   - Check for markers FIRST in `processMessageForQuickActions()`
   - Parse marker type and payload
   - Return detection result with 100% confidence

2. **Pennyfarthing Side (agents/*.md):**
   - Add marker emission guidance to key agents
   - SM: emit `CHOICES` marker when presenting story options
   - All agents: emit `HANDOFF` marker before handoff
   - TEA/Dev: emit `QUESTION:yesno` for confirmations
