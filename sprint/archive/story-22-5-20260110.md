### How It Works

1. **View Menu Toggle**: Custom View menu replaces standard `viewMenu` role, adds "Verbose Mode" checkbox with Cmd+Shift+V accelerator
2. **Settings Store**: In-memory `verboseModeEnabled` state with getter/setter
3. **IPC Channels**:
   - `settings:getVerboseMode` - Get current state
   - `settings:setVerboseMode` - Set state
   - `settings:verboseModeUpdate` - Broadcast changes
4. **Renderer Integration**:
   - On init: Fetch and apply initial verbose mode state
   - On change: Update all existing `<details>` elements and future renders
   - New tool blocks rendered with `open` attribute when verbose mode is on

## Technical Context

### Foundation from Previous Stories

- **settings-store.ts**: In-memory settings with getter/setter pattern
- **IPC channels**: `settings:get*` / `settings:set*` pattern
- **Menu integration**: How to add items to Electron menus

### Implementation Approach
This is a simple story because it leverages existing infrastructure:

1. **Settings Store** (settings-store.ts ~10 lines)
   - Add `getVerboseMode()` / `setVerboseMode()` functions
   - Follow same pattern as `getBashApprovalGate()` / `setBashApprovalGate()`

2. **View Menu Item** (main.ts ~15 lines)
   - Add "Verbose Mode" toggle to View menu
   - Register Cmd+Shift+V keyboard shortcut
   - Wire to settings store

3. **Renderer Integration** (message-view-init.js or app.js ~20 lines)
   - Listen for verbose mode changes via IPC
   - Toggle `open` attribute on existing `<details class="tool-input">` elements
   - Apply to new tool blocks as they render

### Existing DOM Structure
The renderer already creates `<details>` elements for tool blocks:
```javascript
// From MessageView.js (tool use blocks)
<details class="tool-input collapsible">
  <summary>Input</summary>
  <pre><code>${inputJson}</code></pre>
</details>

// From MessageView.js (long results)
<details class="tool-output collapsible">
  <summary>Result for ${tool_id}</summary>
  ...
</details>
```

Just need to conditionally add `open` attribute when verbose mode is enabled.
