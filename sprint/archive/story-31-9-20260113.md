**Scale:** Standard (3 pts) - Full TDD flow

**Optimization Areas:**

1. **Batching Bash commands** - Combine with `&&`
   - `git status && git branch` instead of separate calls
   - `git add . && git commit -m "msg" && git push` in one turn

2. **Parallel tool calls** - More aggressive parallelization
   - Read multiple files in single turn
   - Spawn independent subagents in parallel

3. **Smarter file operations**
   - Grep instead of Read+search (grep reads internally)
   - Glob with brace expansion `{pat1,pat2}` instead of multiple globs

4. **Compound subagents** - Do multiple steps per spawn
   - Combine status-check + file-read into single spawn
   - Merge preflight checks into handoff subagents
