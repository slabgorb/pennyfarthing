## Context

When Claude is running inside Cyclist (our custom Claude REPL wrapper), the statusbar becomes redundant because Cyclist's sidebar already displays:
- Agent persona and character
- Session stats (tokens, messages, context)
- Current story and sprint progress
- Git branch and status

The solution is to detect when running in Cyclist and conditionally disable the statusbar.

## Implementation Details

### Architecture
The implementation uses an environment variable approach:
1. **Cyclist spawns Claude** with `CYCLIST_ACTIVE=1` env var
2. **statusline.sh checks** for this env var
3. **If set, outputs empty string** (disables statusbar)
4. **Sidebar provides same information** as statusbar would

### Files to Modify

#### 1. cyclist/src/server.ts (line ~490)
When spawning the Claude PTY, add CYCLIST_ACTIVE=1 to environment:
```javascript
const ptyProcess = pty.spawn('claude', {
  env: {
    ...process.env,
    CYCLIST_ACTIVE: '1'
  }
});
```

#### 2. pennyfarthing-dist/scripts/statusline.sh
Add check at top of script:
```bash
#!/bin/bash
# If running inside Cyclist, disable statusbar (sidebar shows same info)
if [[ "$CYCLIST_ACTIVE" == "1" ]]; then
  exit 0  # Output nothing
fi

# ... rest of existing statusline.sh logic
```
