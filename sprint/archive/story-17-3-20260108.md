## Review Rejection Summary

**Major Issue (1):** `resolveAgentNames()` regex at story.js:46 double-replaces when input is "Role (Character)" format.
- Example: "Dev (Julia)" becomes "Julia (Julia)" after replacement
- Fix: Use negative lookahead `\b${role}\b(?!\s*\()` to skip replacement when role already has character name in parentheses

## Dev Assessment

**Bug 2 (Token count and context % not populating):**
- Created new API endpoint `/api/token-stats` with WebSocket support at `/ws/token-stats`
- Created new API endpoint `/api/context` that calls `check-context.sh` to get context percentage
- Updated `web-adapter.js` to use these new endpoints
- Added polling in `stats-strip.js` to fetch context percentage every 10 seconds

**Bug 3 (Keys not responding):** Skipped per user request - needs manual testing to identify specific scenarios.

**Bug 4 (AC list collapse):**
- Converted `#acceptance-criteria` div to a full `<section>` with collapsible header (matching todo-section pattern)
- Added CSS for `.ac-section` with collapse/expand animation
- Updated `updateAcceptanceCriteria()` in story.js to populate the new structure
- Removed checkbox circles since there's no event hookup for checking them off

**Bug 5 (Next phase message):**
- Increased font size from 0.7rem to 1rem for `.next-agent`
- Created `/api/theme-agents` endpoint that returns all role-to-character mappings from current theme
- Added `resolveAgentNames()` function in story.js that replaces role names with character names (e.g., "sm" → "Winston", "dev" → "Julia")
