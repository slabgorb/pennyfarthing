## Context
Part of Epic 13: Pennyfarthing Showcase Website

This story involves creating a build-time data pipeline for the Astro showcase project that loads all theme YAML files from pennyfarthing-dist/personas/themes/ and transforms them into a typed TypeScript interfaces and generates a themes.json file for client-side queries.

## Acceptance Criteria
1. All 64 themes loaded at build time
2. TypeScript types for Theme, Agent, OceanScores
3. themes.json generated in public/ for client queries
4. Build completes in < 30 seconds

## Technical Details
- Load from: `pennyfarthing-dist/personas/themes/*.yaml`
- Output: `showcase/public/themes.json` (~500KB estimated)
- Cache theme data during build for performance
- Transform YAML to typed TypeScript interfaces

### Theme YAML Structure (63 themes, 630 personas)

Each theme file follows this structure:
```yaml
theme:
  name: string           # "Vorkosigan Saga"
  description: string    # Brief description
  source: string         # "Vorkosigan Saga (1986-present), Lois McMaster Bujold"
  default_emoji_use: string  # "minimal" | "moderate" | etc
  default_humor: string      # "enabled" | "disabled"
  character_immersion: string # "high" | "medium" | "low"
  user_title: string     # "My Lord"

agents:
  <role>:               # sm, tea, dev, reviewer, architect, pm, tech-writer, ux-designer, devops, orchestrator
    character: string   # "Miles Vorkosigan"
    ocean:
      O: 1-5           # Openness
      C: 1-5           # Conscientiousness
      E: 1-5           # Extraversion
      A: 1-5           # Agreeableness
      N: 1-5           # Neuroticism
    style: string
    expertise: string
    role: string
    quote: string
    trait: string
    quirks: string[]
    catchphrases: string[]
    emoji: string
    helper:
      name: string
      style: string
```

### TypeScript Interfaces Needed

```typescript
interface OceanScores {
  O: number; // 1-5
  C: number;
  E: number;
  A: number;
  N: number;
}

interface AgentHelper {
  name: string;
  style: string;
}

interface Agent {
  role: string;        // Key from agents map
  character: string;
  ocean: OceanScores;
  style: string;
  expertise: string;
  roleSummary: string; // renamed from 'role' to avoid conflict
  quote: string;
  trait: string;
  quirks: string[];
  catchphrases: string[];
  emoji: string;
  helper: AgentHelper;
}

interface ThemeMetadata {
  name: string;
  description: string;
  source: string;
  defaultEmojiUse: string;
  defaultHumor: string;
  characterImmersion: string;
  userTitle: string;
}

interface Theme {
  id: string;          // filename without .yaml (e.g., "vorkosigan-saga")
  metadata: ThemeMetadata;
  agents: Agent[];
}
```
