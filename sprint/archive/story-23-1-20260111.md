**Data Flow Pattern:**

```typescript

  TOKEN_STATS_UPDATE: 'tokenStats:update',
  CONTEXT_GET: 'context:get',
  CONTEXT_UPDATE: 'context:update',
  // Add: USAGE_STATS_GET, USAGE_STATS_UPDATE
};
```

**Preload Pattern (preload.ts L285-308):**
```typescript
stats: createDataAPI(ipcRenderer, 'stats:get', 'stats:update'),

// Add: usageStats: createDataAPI(ipcRenderer, 'usageStats:get', 'usageStats:update')
```

**Stats Strip Pattern (stats-strip.js):**
- Uses `window.electronAPI.context.get()` for initial load

- Updates DOM with data-stat attributes
- Level classes: safe (>50%), warning (>20%), danger (>5%), critical
