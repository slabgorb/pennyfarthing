See `.session/context-story-31-7.md` for full technical analysis.

### Problem
5 separate handoff subagents with duplicated logic:
- tea-handoff.md, dev-handoff.md, sm-handoff.md
- reviewer-handoff-approve.md, reviewer-handoff-reject.md

### Solution
Single generic-handoff.md that:
1. Reads workflow name and current phase from session file
2. Loads workflow definition from .claude/workflows/{name}.yaml
3. Looks up gate type for current phase
4. Runs gate-specific checks
5. Updates session with phase transition

### Gate Types
| Gate | Check | Used By |
|------|-------|---------|
| tests_pass | Run tests, verify GREEN | dev |
| tests_fail | Run tests, verify RED | tea |
| approval | Check APPROVED verdict | reviewer (approve path) |
| rejection | Check REJECTED, route back | reviewer (reject path) |
| manual | Verify section exists | sm |
