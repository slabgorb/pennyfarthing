### Key Types (Already Defined)

From `telemetry-types.ts` (L326-351):

```typescript
export type TDDPhase = 'RED' | 'GREEN' | 'REFACTOR' | 'REVIEW';

export interface PhaseTransition {
  phase: TDDPhase;
  timestamp: number;  // Unix ms
  agent?: string;     // Which agent initiated
}

export interface TDDMetrics {
  storyId: string;
  currentPhase: TDDPhase;
  phaseTransitions: PhaseTransition[];
  phaseDurations: {
    RED?: number;      // ms in RED phase
    GREEN?: number;    // ms in GREEN phase
    REFACTOR?: number; // ms in REFACTOR phase
    REVIEW?: number;   // ms in REVIEW phase
  };
  cycleCount: number;  // Number of RED→GREEN cycles
  averageRedToGreen?: number;  // Average ms from RED to GREEN
}
```

#### 2. api/telemetry.ts (NEW - TDD endpoint)

Express router for TDD metrics:

```typescript
import { Router } from 'express';
import { getTDDMetrics } from '../tdd-metrics.js';

export function createTelemetryRouter(): Router {
  const router = Router();

  router.get('/tdd', (req, res) => {
    const metrics = getTDDMetrics();
    if (!metrics) {
      return res.status(404).json({ error: 'No TDD metrics available' });
    }
    res.json(metrics);
  });

  return router;
}
```

### Session File Format

The session file contains a status table that indicates current phase:

```markdown
## Status

| Field | Value |
|-------|-------|
| Phase | RED |
| Agent | TEA |
| Started | 2026-01-10 |
```

Parse this to detect phase. When phase changes (e.g., TEA→Dev handoff changes RED→GREEN), record the transition.
