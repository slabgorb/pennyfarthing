# Story 33-4: Spot Permission Grants

## Story Info
- **Epic:** 33 (Runtime Permission Management)
- **Points:** 2
- **Priority:** P1
- **Repos:** pennyfarthing, cyclist
- **Jira:** MSSCI-11686

## Objective
Implement three grant scopes for permission approvals:
- "Allow once" - single use, auto-revoked after use
- "Allow for this session" - memory only, clears on exit
- "Always allow" - persists to settings.local.json

## Acceptance Criteria
- [ ] AC1: Three grant scopes implemented (once, session, always)
- [ ] AC2: UI reflects scope selection (three buttons)
- [ ] AC3: Session grants clear on exit (memory only)
- [ ] AC4: Persistent grants survive restart (settings.local.json)
