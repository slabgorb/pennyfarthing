# Story 35-7: Custom styling themes

**Epic:** 35 (Cyclist UI/UX Improvements)
**Story ID:** 35-7
**Jira Key:** MSSCI-11722
**Repository:** cyclist
**Points:** 5
**Priority:** P2

## Overview

Full custom theme system replacing hardcoded dark/light themes. Users can create, edit, import, and share complete visual themes with live preview, theme inheritance, and CSS variable integration.

## Scope

- Define comprehensive theme schema (UI colors, terminal palette, syntax highlighting, panel borders, accent colors)
- Theme editor UI for creating/modifying themes in-app
- Live preview while editing theme colors
- Load themes from JSON files or config
- Theme browser in settings to preview and select
- Built-in theme gallery with variety of styles (dark, light, solarized, monokai, nord, dracula)
- Support importing custom themes from JSON/URL
- Export current theme for sharing
- Theme inheritance (extend existing theme, override specific colors)
- CSS variable integration for instant theme switching

## Implementation Plan

1. **Theme Schema Definition**
   - Create comprehensive JSON schema for themes
   - Include UI colors (backgrounds, borders, text, accents)
   - Include terminal palette (16 ANSI colors + background/foreground)
   - Include syntax highlighting colors
   - Support theme metadata (name, description, author, extends)
   - Document all required and optional fields

2. **Theme System Core**
   - ThemeManager class to load, validate, and apply themes
   - localStorage persistence for user-created themes
   - Theme validation against schema
   - Support for theme inheritance (extend base theme, override specific colors)

3. **Built-in Themes**
   - Dark (default dark theme)
   - Light (bright theme for daytime use)
   - Solarized (precision colors for machine and people)
   - Monokai (dark theme with vibrant accent colors)
   - Nord (arctic, north-bluish color palette)
   - Dracula (dark theme with saturated colors)

4. **Theme Editor Component**
   - Visual UI for editing theme colors
   - Color picker component (hex/RGB input, visual picker)
   - Organized sections by color category (UI colors, terminal palette, syntax)
   - Create new theme from scratch
   - Create new theme by extending existing theme
   - Edit theme metadata (name, description, author)
   - Save to localStorage or export to file

5. **Theme Browser**
   - Settings panel section showing theme gallery
   - Preview of each theme (color swatches, sample text)
   - Click to apply theme
   - Show current active theme
   - Sort by name or category

6. **Live Preview**
   - Real-time preview as colors are edited
   - Apply theme changes instantly (CSS variables)
   - No page reload required
   - Preview both UI and terminal colors

7. **Import/Export**
   - Import theme from JSON file (drag-drop or file picker)
   - Import theme from URL
   - Export current theme to JSON file
   - JSON includes all metadata and color definitions

8. **CSS Variable Integration**
   - All colors defined as CSS custom properties
   - Update CSS variables when theme changes
   - Supports both light and dark terminal themes

## Acceptance Criteria

- Theme schema documented (JSON format with all color categories)
- Theme editor UI with color pickers for each theme property
- Live preview updates as colors are changed
- At least 6 built-in themes (dark, light, solarized, monokai, nord, dracula)
- Theme browser shows preview of each theme
- Custom themes can be created from scratch or by extending existing
- Themes can be imported from JSON file or URL
- Current theme can be exported to JSON for sharing
- Terminal colors update with theme
- Syntax highlighting colors configurable per theme
- Theme changes apply instantly without page reload

## Technical Notes

- Extends existing Cyclist settings panel
- Integrates with IPC for theme persistence
- Terminal (xterm.js) respects theme colors
- CSS custom properties for theming support
- JSON schema for validation
