## Overview

Surface permission denials in Cyclist UI so users understand why operations failed and how to grant permissions.

## Acceptance Criteria

- [x] Result messages display permission_denials when present

- [x] Styled with warning colors (red/orange border)
- [x] Test coverage for denial rendering

## Technical Approach

1. **Extend renderResultMessage** in `message-renderers.js`

   - Build HTML for denial list if present
   - Add `has-denials` class for styling

2. **CSS Styling** in `styles.css`
   - Warning colors (red border, light red background)
   - Denial list with tool names and targets
   - Help text with remediation instructions

3. **Test Coverage** in `B-14-message-display.test.ts`
   - Test denial rendering with mock data
   - Verify HTML structure and classes
