**What was implemented:**

The skill suggestions utility provides three complementary functions for discovering relevant skills:

1. **suggestFromSession()** - Context-aware suggestions based on current story/task:
   - Analyzes phase (planning, development, review, etc.)
   - Extracts keywords from acceptance criteria
   - Maps to relevant skills

2. **suggestFromKeywords()** - User input analysis:
   - Extracts keywords from text
   - Matches against skill registry descriptions and tags
   - Ranks by relevance score (0-1)

3. **suggestSkills()** - Main entry point:
   - Combines session-aware and keyword-based suggestions
   - Merges scores for skills found in both sources
   - Filters by confidence threshold (default 0.3)
   - Returns up to 5 results by default

**Technical details:**
- Reuses searchSkills() from skill-search.ts for registry access
