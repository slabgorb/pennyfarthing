## Story Summary

When an agent invokes the handoff subagent, make intelligent decisions based on context usage and user settings:
- Low context with auto mode: Handoff immediately
- Low context with manual mode: Offer handoff
- High context with auto mode: Compact then invoke+prime new agent
- High context with manual mode: Offer handoff with warning

## Acceptance Criteria

- [ ] generic-handoff checks context percentage before handoff
- [ ] Context < 50% with auto_handoff: Immediate handoff
- [ ] Context < 50% without auto_handoff: Offer handoff
- [ ] Context > 50% with auto_handoff: Compact then invoke+prime new agent
- [ ] Context > 50% without auto_handoff: Offer handoff with warning
- [ ] auto_handoff setting configurable in workflow or project config
- [ ] Session file tracks context percentage at handoff points
- [ ] Works with all workflow types (TDD, trivial, custom)
- [ ] Cyclist settings UI uses radio button group for handoff mode (not checkboxes)
- [ ] Radio options: "Auto handoff" / "Manual handoff (ask first)"
- [ ] Setting persists and is correctly read by generic-handoff subagent
- [ ] End-to-end test: change setting, trigger handoff, verify behavior matches
