### Skill Pattern
Skills are markdown files in `pennyfarthing-dist/skills/{name}/SKILL.md` with:
- Frontmatter: name, description, invocable: true
- Purpose section
- Commands section with usage examples
- Reference to underlying code when applicable

### Implementation Approach
1. Create skill file at `pennyfarthing-dist/skills/workflow/SKILL.md`
2. Define three commands: list, show, set
3. Reference workflow loader for listing
4. Reference session file for current position
5. Create symlink in `.claude/skills/workflow/`
