## Technical Approach

Create a background task tracking utility that:
1. **Records tasks** when spawned with `run_in_background: true`
2. **Updates status** when results are checked
3. **Cleans up** completed tasks from session file

### Implementation

Create `scripts/utils/background-tasks.sh`:

```bash
#!/usr/bin/env bash
# Background task tracking utilities

# Add a background task to session file
# Usage: bg_task_add <session_file> <task_id> <subagent_type> <description>
bg_task_add() {
    local session_file="$1"
    local task_id="$2"
    local subagent_type="$3"
    local description="$4"
    local timestamp=$(date +"%H:%M")

    # Create Background Tasks section if missing
    if ! grep -q "^## Background Tasks" "$session_file" 2>/dev/null; then
        echo -e "\n## Background Tasks\n\n| Task ID | Type | Started | Status | Description |\n|---------|------|---------|--------|-------------|" >> "$session_file"
    fi

    # Add task row
    sed -i '' "/^## Background Tasks/,/^## /{/^|.*|$/a\\
| $task_id | $subagent_type | $timestamp | running | $description |
}" "$session_file"
}

# Update background task status
# Usage: bg_task_update <session_file> <task_id> <status>
bg_task_update() {
    local session_file="$1"
    local task_id="$2"
    local status="$3"  # running, completed, error

    sed -i '' "s/| $task_id |\\(.*\\)| running |/| $task_id |\\1| $status |/" "$session_file"
}

# Remove completed background tasks
# Usage: bg_task_cleanup <session_file>
bg_task_cleanup() {
    local session_file="$1"
}

# List active background tasks
# Usage: bg_task_list <session_file>
bg_task_list() {
    local session_file="$1"
    grep "| running |" "$session_file" 2>/dev/null || echo "No active background tasks"
}
```

### Agent Integration

Update agent guides to use these utilities:

**Before spawning background task:**
```bash
source $CLAUDE_PROJECT_DIR/scripts/utils/background-tasks.sh
SESSION_FILE="$CLAUDE_PROJECT_DIR/.session/${STORY_ID}-session.md"
# After Task tool returns task_id:
bg_task_add "$SESSION_FILE" "$TASK_ID" "testing-runner" "Background test run"
```

**After checking TaskOutput:**
```bash
bg_task_update "$SESSION_FILE" "$TASK_ID" "completed"  # or "error"
bg_task_cleanup "$SESSION_FILE"  # Remove finished tasks
```

### Validation in workflow-status-check

Add background task detection to `workflow-status-check.md`:

```bash
# Check for orphaned background tasks
if grep -q "| running |" "$SESSION_FILE" 2>/dev/null; then
    echo "WARNING: Active background tasks found:"
    bg_task_list "$SESSION_FILE"
fi
```

## Reviewer Assessment

**Verdict: REJECT**

### Critical Bug Found

The `grep -c` pattern on lines 110, 112, 162, 164, 166 of `background-tasks.sh` is broken:

```bash
# Current (broken):
completed_count=$(grep -c "| completed |" "$session_file" 2>/dev/null || echo "0")
```

When grep finds 0 matches, it outputs "0" AND exits 1. The fallback `|| echo "0"` then appends, resulting in "0\n0".

**Impact:**
- `bg_task_cleanup()` output broken: "Cleaned up 0\n0 completed, 0\n0 errored tasks"
- `bg_task_summary()` output broken
- Numeric comparison on line 114 may fail

### Required Fix

Replace all 5 occurrences with:
```bash
completed_count=$(grep -c "| completed |" "$session_file" 2>/dev/null) || completed_count=0
```
