## Technical Context

**File to create:** `packages/cyclist/src/telemetry-types.ts`

**Core Types Required:**
- `AgentSpan` - Parent span for agent execution with OTEL gen_ai.* attributes
- `ToolSpan` - Child span for each tool call
- `PromptEvent` - Event structure for prompts/completions
- `TokenUsage` - Token counting interface
- `CostAttribution` - Cost tracking per agent/story

**OTEL Semantic Conventions:**
- `gen_ai.system` = 'claude'
- `gen_ai.request.model` = model name
- `gen_ai.usage.input_tokens` = input token count
- `gen_ai.usage.output_tokens` = output token count
- `gen_ai.usage.total_cost_usd` = cost in USD

**Pennyfarthing Extensions:**
- `pennyfarthing.agent` = sm/tea/dev/reviewer
- `pennyfarthing.story_id` = active story ID
- `pennyfarthing.theme` = current theme

**Reference:** See `.session/context-epic-19.md` lines 119-179 for complete type definitions.
