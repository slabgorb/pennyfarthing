## Description

Enable end users to customize agent behavior using Claude Code's native output styles feature plus a Pennyfarthing preferences file.

**Output Styles** (ship in pennyfarthing-dist/output-styles/):
- `verbose.md` - Detailed explanations, educational
- `terse.md` - Minimal output, just the essentials
- `teaching.md` - Explains decisions, suggests alternatives

**User Preferences** (new file: `.claude/pennyfarthing/preferences.yaml`):
- `character_voice: true/false` - Enable/disable persona flavor
- `explain_decisions: true/false` - Show reasoning
- `auto_commit: true/false` - Auto-commit on story completion

**CLI Integration:**
- `pennyfarthing init` creates preferences.yaml with defaults
- `agent-session.sh` reads preferences and adjusts behavior
- Document in README how to customize

Leverages Claude Code's native `/output-style` command.

### Design Decisions

1. **Preferences location:** `.claude/pennyfarthing/preferences.yaml`
   - Keeps all pennyfarthing config in one place
   - `.local.yaml` override pattern for personal preferences

2. **Output styles format:** Claude Code native format
   - Simple markdown files with style instructions
   - User invokes via `/output-style verbose` etc.

3. **character_voice effect:** When false, persona output is suppressed
   - `agent-session.sh` checks preference before outputting persona XML
   - Allows "professional mode" without character flavor
