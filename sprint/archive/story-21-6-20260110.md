### Context-Aware Behavior

The /help command should detect context and show relevant info:

1. **No active session:** Show quick-start, emphasize `/work` and `/new-work`
2. **Session exists (dev phase):** Show `/check`, `/reviewer` as next steps
3. **Session exists (review phase):** Show `/sm` for finish workflow
4. **Theme query:** Show current theme with character mappings

### Script Implementation

**File 2: pennyfarthing-dist/scripts/help.sh** (optional - can be pure markdown)

If script needed for dynamic content:
```zsh
#!/usr/bin/env zsh
# help.sh - Context-aware Pennyfarthing help

set -euo pipefail
source "$(dirname "$0")/utils/find-root.sh"

# Detect current state
SESSION_FILE=$(find "$PROJECT_ROOT/.session" -name "*-session.md" -type f 2>/dev/null | head -1)
THEME=$(yq '.theme' "$PROJECT_ROOT/.claude/persona-config.yaml" 2>/dev/null || echo "unknown")

# Output help based on context
if [[ -z "$SESSION_FILE" ]]; then
    echo "# Quick Start"
    echo "No active session. Use /work or /new-work to begin."
else
    PHASE=$(grep -m1 "Phase:" "$SESSION_FILE" | sed 's/.*Phase://' | tr -d ' *')
    echo "# Current Work"
    echo "Session: $(basename "$SESSION_FILE" .md)"
    echo "Phase: $PHASE"
fi
```
