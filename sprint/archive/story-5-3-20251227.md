## Description
CLI command to create a custom theme from a template.

Usage:
```
pennyfarthing theme create my-theme
pennyfarthing theme create my-theme --base shakespeare
```

Creates:
```
.claude/pennyfarthing/themes/my-theme.yaml
```

Implementation:
- Copy base theme (default: minimalist) to user themes dir
- Open in $EDITOR or provide path for manual editing
- Register in persona-config.yaml custom_themes list

Custom themes loaded from:
- .claude/pennyfarthing/themes/ (project-level)
- ~/.claude/pennyfarthing/themes/ (user-level)

## Acceptance Criteria
1. pennyfarthing theme create <name> creates new theme file
2. --base flag copies from existing theme
3. Theme file has correct YAML structure
4. Custom themes appear in 'theme list' output
5. User-level themes work across projects
