## Technical Notes

### Running Generation
```bash
source ~/.venvs/sd/bin/activate
python3 showcase/src/data/sprite-prompts/generate-sprites.py --theme THEME_NAME --skip-existing
```

### Parallel Generation (3 at a time)
```bash
# Run each in separate terminal or background
python3 showcase/src/data/sprite-prompts/generate-sprites.py --theme THEME1 &
python3 showcase/src/data/sprite-prompts/generate-sprites.py --theme THEME2 &
python3 showcase/src/data/sprite-prompts/generate-sprites.py --theme THEME3 &
```

### Time Estimates
- ~2.5 minutes per portrait (with 3 parallel)
- ~25 minutes per theme
- ~5 hours total with 3x parallelism

### Key Files
- Script: `showcase/src/data/sprite-prompts/generate-sprites.py`
- Output: `showcase/public/sprites/{theme}/{role}.png`
- Prompts: `showcase/src/data/sprite-prompts/{theme}.md`
