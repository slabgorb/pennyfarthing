### New Backend Endpoints Needed

**1. GET /api/story**
Returns current story context from Pennyfarthing session files.

```typescript
interface StoryInfo {
  id: string | null;        // "15-3"
  title: string | null;     // "Enhance Cyclist sidebar..."
  phase: string | null;     // "dev", "tea", "review", etc.
  status: string | null;    // "in_progress", "approved"
  points: number | null;    // 3
  sprint: {
    number: number;         // 6
    completed: number;      // 56
    total: number;          // 68
  } | null;
}
```

Implementation approach:
- Read `.session/*-session.md` files (find most recent or use SESSION_ID)
- Parse YAML frontmatter or markdown structure for story metadata
- Read `sprint/current-sprint.yaml` for sprint progress
- Return null fields gracefully if files missing

**2. GET /api/git**
Returns git status for the project directory.

```typescript
interface GitInfo {
  branch: string;           // "feature/15-3-cyclist-sidebar"
  clean: boolean;           // true if no uncommitted changes
  ahead: number;            // commits ahead of remote
  behind: number;           // commits behind remote
}
```

Implementation approach:
- Run `git rev-parse --abbrev-ref HEAD` for branch
- Run `git status --porcelain` to check clean/dirty
- Run `git rev-list --count HEAD..@{u}` for ahead/behind (handle no upstream)
- Use `child_process.execSync` with cwd set to project dir

### Dependencies & Risks

1. **Session file format:** Parsing markdown with YAML-like frontmatter is fragile. Use regex or simple line parsing rather than full YAML parser on markdown.

2. **Git command failures:** Handle cases where:
   - Not a git repo (return null)
   - No upstream set (ahead/behind = null)
   - Git not installed (graceful error)

3. **Portrait symlink:** Story 15-4 handles the symlink setup. For now, use fallback placeholder if sprites not available.

4. **Polling frequency:** Git status polling at 5s is reasonable. Story changes are rare, could poll at 10s.
