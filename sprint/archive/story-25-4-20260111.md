## Technical Context

### Current State Analysis

The `QUESTION_PATTERNS` array in `quick-actions.js` (lines 86-103) already has SOME yes/no detection:

```javascript
export const QUESTION_PATTERNS = [
  // Direct action offers - these imply readiness to proceed
  { pattern: /would you like me to/i, responses: ['Yes, proceed', 'No'], requiresQuestion: false },
  { pattern: /shall i (proceed|continue|go ahead|start|begin)/i, responses: ['Yes, proceed', 'No'], requiresQuestion: false },
  { pattern: /ready to proceed/i, responses: ['Yes, proceed', 'Hold on'], requiresQuestion: false },
  { pattern: /want me to (proceed|continue|go ahead|start|begin)/i, responses: ['Yes, proceed', 'No'], requiresQuestion: false },

  // Yes/No questions - require actual question mark
  { pattern: /should i\b/i, responses: ['Yes', 'No'], requiresQuestion: true },
  { pattern: /do you want/i, responses: ['Yes', 'No'], requiresQuestion: true },
  { pattern: /shall i\b/i, responses: ['Yes', 'No'], requiresQuestion: true },
  // ... permission prompts
];
```

### Gap Analysis

**Covered well:**
- "would you like me to..." ✓
- "shall I proceed/continue/go ahead/start/begin" ✓
- "should I..." (requires ?) ✓

**Gaps/Issues:**
1. **"ready to X" is too narrow** - only matches "ready to proceed", not "ready to continue", "ready to start", etc.
2. **"proceed with" not detected** - "shall I proceed with the changes?" might not match
3. **Inconsistent responses** - some use "Yes, proceed"/"No", others "Yes"/"No", one uses "Hold on"
4. **Missing patterns:**
   - "shall I claim..." / "shall I invoke..." - action verbs beyond proceed/continue/go ahead/start/begin
   - "do you want me to..." (different from "want me to")
   - "can I..." / "may I..."
   - "is it okay to..." / "is it ok if..."
   - "are you ready for me to..."
   - General "shall I [verb]" should work for ANY action verb, not just the 5 hardcoded ones

### Story Goal

Make yes/no detection **universal and consistent**:
1. Cover ALL common confirmation phrasings
2. Use consistent response labels
3. Ensure detection works WITHOUT numbered options
4. Handle both question-mark and non-question-mark forms appropriately

### Implementation Approach

1. **Audit and expand QUESTION_PATTERNS** - Add missing patterns
2. **Standardize responses** - Use consistent "Yes, proceed"/"No" or "Yes"/"No"
