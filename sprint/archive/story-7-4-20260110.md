## Context

### Current Infrastructure

Job-fair currently produces per-theme results in `internal/results/job-fair/{theme}-{timestamp}/summary.yaml` but there's no aggregation across themes.

**Existing files:**
- `scripts/job-fair-runner.sh` - Orchestrates per-theme runs (279 lines)
- `scripts/solo-runner.sh` - Single benchmark execution (345 lines)
- `packages/core/src/scripts/benchmark-integration.ts` - Analytics layer (944 lines)
- `pennyfarthing-dist/commands/job-fair.md` - Command specification (388 lines)

### Files to Create

- `scripts/aggregate-job-fair.sh` - Shell aggregation script
- `packages/core/src/scripts/job-fair-aggregator.ts` - TypeScript aggregation module
- `internal/results/job-fair/aggregate/` - Aggregated results directory

### Data Format

Per-theme summary.yaml contains:
- `champions`: Per-role winners with scores
- `matrix`: Character → Role → Score grid
- `overall_rankings`: Characters sorted by average
- `role_rankings`: Within-role rankings

Aggregate output should contain:
- `themes_included`: List of aggregated themes
- `by_role`: Mean, std_dev, top performers per role
- `overall_champions`: Cross-theme top performers
- `historical_trend`: Score trends over time
