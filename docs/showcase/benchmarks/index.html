Performance Benchmarks

Comparing persona agents against control baselines across 13 scenarios. Scores range from 0-100, with delta showing improvement over control.

How Benchmarks Work

Each persona agent is evaluated on standardized scenarios and scored by an independent judge. The delta shows how much a persona improves (or regresses) compared to a control agent without personality.

  • Score: 0-100 scale based on task completion, quality, and persona adherence
  • Delta vs Control: Positive means persona outperforms baseline
  • OCEAN: Big Five personality traits (Openness, Conscientiousness, Extraversion, Agreeableness, Neuroticism)
