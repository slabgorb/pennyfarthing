## How Job Fair Works

The Job Fair process:

1. **Benchmarks each character** against each agent role using OCEAN personality profiles
2. **Scores fit** on a 100-point scale based on personality trait alignment
3. **Identifies swaps** where a different character would score higher
4. **Calculates deltas** showing improvement from optimization
5. **Validates or optimizes** character assignments

Themes with higher scores and larger deltas have more confidence in their character-to-role mappings.
