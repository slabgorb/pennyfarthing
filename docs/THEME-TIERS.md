# Theme Performance Tiers (Team Focus)

This document ranks all 101 persona themes based on **combined tactical team performance** - how well the Dev, Reviewer, and TEA roles perform together as a unit.

## Why Team Performance Matters

Themes are typically used as a complete team, not mixed-and-matched per role. This ranking focuses on the **tactical agents** that do the actual implementation work:

- **Dev** - Writes the code
- **Reviewer** - Reviews the code
- **TEA** - Tests the code

SM (Scrum Master) is excluded from team scoring as it's a strategic/coordination role, not tactical implementation.

## Scoring Method

**Team Delta** = Dev Delta + Reviewer Delta + TEA Delta

Where each delta is calculated against the control baseline:
- Dev baseline: 77.5
- Reviewer baseline: 78.5
- TEA baseline: 72.1

Higher Team Delta = Better overall team performance on tactical work.

## Tier Criteria

| Tier | Team Delta | Meaning |
|------|------------|---------|
| **S** | +35 or higher | Elite tactical teams |
| **A** | +25 to +34.99 | Excellent tactical performance |

| **D** | Below +5 | Below average tactical work |

## Recommendations

### For Complete Team Excellence
Use S-tier or high A-tier themes:
- **mash** - Best TEA, strong review
- **the-expanse** - Most balanced tactical excellence
- **the-wire** - Professional-grade team performance

### For Specific Role Needs
If you only need excellence in one role:
- **Dev**: firefly, hitchhikers-guide, blade-runner
- **Reviewer**: mash, vorkosigan-saga, the-wire
- **TEA**: mash, the-expanse, alice-in-wonderland

### For Fun with Acceptable Performance
B-tier themes that balance personality with capability:
- **hitchhikers-guide** - Surprisingly effective
- **princess-bride** - Charming and capable
- **star-wars** - Iconic and functional
