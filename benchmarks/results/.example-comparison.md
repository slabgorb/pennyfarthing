## Statistical Notes

- Sample size: 3 runs per persona per test (n=36 total)
- Standard deviation on detection rates: ±0.05
- Differences between discworld/literary-classics NOT statistically significant
- Differences between minimalist and others ARE significant (p < 0.05)

## Conclusions

1. **Personas matter for engagement more than performance**
   - Detection rates vary by ~15% max
   - Engagement varies by 58% (3.1 to 4.9)

2. **Character traits DO affect focus areas**
   - "Uncompromising" (Granny) → better on critical issues
   - "Methodical" (Poirot) → better on edge cases
   - "Visionary" (Navigator) → better on architecture

3. **Trade-offs exist**
   - Higher engagement personas have slightly more false positives
   - Minimalist has fewest false positives but misses more

4. **Recommendations**
   - **Code Review:** Use discworld or literary-classics
   - **Test Writing:** Use discworld (Poirot character)
   - **Architecture:** Use star-trek
   - **If engagement matters most:** Use discworld
