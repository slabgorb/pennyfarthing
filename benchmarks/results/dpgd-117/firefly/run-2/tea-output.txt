### Expected Public API Surface

The tests expect the dev to implement:
1. `axiathon_server::app() -> Router` — builds the app with default config
2. `axiathon_server::app_with_config(ServerConfig) -> Router` — builds with custom config
3. `axiathon_server::ServerConfig` — with `test_config_with_rate_limit(limit: u32)` constructor and `Clone`

### Delivery Findings

- **Gap** (non-blocking): Current `ApiMeta` in axiathon-core has pagination fields (total/limit/offset) but AC requires meta with `request_id`, `timestamp`, `trace_id`. The server layer needs either a new `ResponseMeta` type or the existing `ApiMeta` needs to be extended.
  Affects `crates/axiathon-core/src/types.rs` (ApiMeta struct needs request_id/timestamp/trace_id fields).
  *Found by TEA during test design.*

- **Gap** (non-blocking): Current `ApiResponse.error` is a singular `Option<ApiError>` but AC requires `errors` as an always-present array. The serialization shape needs adjustment for the HTTP layer.
  Affects `crates/axiathon-core/src/types.rs` (ApiResponse envelope shape).
  *Found by TEA during test design.*
