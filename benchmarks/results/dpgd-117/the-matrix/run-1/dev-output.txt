### Architecture

- **Middleware stack** (outside → in): `DefaultBodyLimit(1MB)` → CORS → Auth → Rate Limit → Handler
- **Response envelope**: `{ data, errors: [], meta: { request_id, timestamp, trace_id } }` on every response
- **Auth**: Skips public paths (health, JWKS, OPTIONS); validates Bearer tokens and X-API-Key headers; checks per-route scopes
- **Rate limiting**: 100 requests per tenant, independent counters, health exempt
- **Security**: No internal details in error responses, `#![forbid(unsafe_code)]`, body size limits
