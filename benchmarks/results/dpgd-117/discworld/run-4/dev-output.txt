**Architecture:**
- Public routes (health, JWKS) have no auth
- Protected routes go through auth middleware → rate limiter → scope check in handler
- All responses use the three-field envelope (`data`, `errors[]`, `meta{request_id, timestamp, trace_id}`)
- CORS preflight handled at outermost middleware layer
- Security headers (`X-Content-Type-Options: nosniff`, `X-API-Version: v1`) on all responses
- CWE-209 compliant: error messages are generic, no internal details leaked
