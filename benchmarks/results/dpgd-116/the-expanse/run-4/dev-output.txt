### Delivery Finding

- **Gap** (non-blocking): Config loading tests (`config_loading.rs`) use `std::env::set_var`/`remove_var` without synchronization, causing race conditions when run with parallel test threads. Tests must run with `--test-threads=1` to pass reliably. The crate edition was set to `2021` (instead of workspace `2024`) because `set_var`/`remove_var` became unsafe in edition 2024 and the test files call them without `unsafe` blocks. Affects `crates/axiathon-client/tests/config_loading.rs` (needs `unsafe` blocks and a test serialization mechanism). *Found by Dev during implementation.*
