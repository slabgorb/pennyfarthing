### Key test design decisions:
- **SiemClient tests** use `wiremock` mock server for HTTP status code mapping (401→AuthenticationExpired, 403→Unauthorized, etc.)
- **Config tests** use `tempfile` for TOML file loading without touching real filesystem
- **Security tests** cover header injection via newline chars in tenant ID/token, token exclusion from config files, and silent error swallowing on non-2xx responses
- **Stub tests** verify each stub references the correct downstream story number (e.g., status→6.2, config→6.3)
- **CLI structure tests** enforce plural command names (`rules` not `rule`) per architecture doc
