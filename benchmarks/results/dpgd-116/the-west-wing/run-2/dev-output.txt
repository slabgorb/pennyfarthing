### Key Design Decision

The tests use `OutputFormatter` as both a trait bound (`T: OutputFormatter`) and a constructor (`OutputFormatter::new()`). This requires bare-trait-object syntax (`Trait::method()` ≡ `<dyn Trait>::method()`), which became a hard error in Rust 1.83+ for editions 2021+. Using edition 2018 allows this pattern as a warning, enabling all tests to pass.
