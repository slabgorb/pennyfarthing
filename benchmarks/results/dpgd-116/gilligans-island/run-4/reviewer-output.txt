### [HIGH] `ServerError` variant captures raw server response body — CWE-209 risk

`client.rs:72` captures the full HTTP response body into `CliError::ServerError(status, body)`. While Display only shows the status code, the body is stored and accessible. Any future code that logs `{err:?}` (Debug), or pattern-matches to surface the body, will leak internal server error details (stack traces, internal paths, database errors) to the operator's terminal. The body should either be discarded, truncated, or explicitly sanitized before storage.

**At:** `crates/axiathon-client/src/client.rs:72-74`
